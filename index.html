What it does

Four things designers actually need.

Every feature is one click away. Every change syncs to your team. Every reference lives in your Figma file.

01 / Visual search

Search by what it looks like, not what it's called.

A CLIP model runs locally in your browser. Click 🔍 on any card to re-sort by visual similarity, or type a query like "warm sunset architecture" and watch the grid resort by meaning, not keywords.

CLIP ViT-B/32 ~40 MB offline after first load
02 / Arrange

Seven moodboard layouts. One click. Fully editable.

Pick references, hit Arrange, get a real Figma auto-layout frame. Grid, Masonry, Hero, Magazine, Filmstrip, Row, Polaroid. Drag items between cells after — it's all native Figma.

auto-layout editable no exports
03 / Extract

Turn a reference into a design system.

One click on any reference creates real Figma variables — color, spacing, radius — plus paint styles and text styles. Apply them like any other token. Idempotent: re-run on the same ref to update in place.

5 color vars 8 spacing vars 6 text styles variables, not exports
04 / Team mode

Multiplayer because the file is multiplayer.

The library is just rectangles on a hidden Figma page. When a teammate adds something, you see it in real time. Reactions, comments, activity feed — all included, zero infrastructure.

Architecture

Three files. No build step. No telemetry.

The whole plugin is a manifest, a sandbox script, and one HTML file. Easy to read, easy to fork, easy to trust.

clipform/ 
manifest.json    Plugin metadata, permissions, allowed domains
code.js          Sandbox — talks to the Figma document via figma.* API
ui.html          UI iframe — rendering, capture, CLIP, multiplayer

Everything lives on a hidden page in your Figma file (📌 Clipform Library). Each reference is a rectangle with the image as a fill plus JSON metadata in pluginData. The hidden page travels with the file — Figma's multiplayer handles real-time sync for the team for free.
